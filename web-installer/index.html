⚠️ Browser Compatibility This installer only works in Chrome, Edge, or Opera browsers. Firefox and Safari do NOT support Web Serial API.

📋 Requirements

  • LilyGO T-Dongle S3 (or compatible ESP32-S3 board)
  • Chrome, Edge, or Opera browser
  • USB cable that supports data transfer (not charging-only)

🎯 After Installation

  1. Device will reboot and display TINY OS v2.0 on screen
  2. Look for WiFi network: TinyOS-XXXX
  3. Connect using password: TinyOS123
  4. Open browser: http://192.168.4.1
  5. Enjoy your pocket computer! 🎉

🎮 What You Get

  • Games: Snake, Pong, 2048 with keyboard controls
  • Terminal: Run commands (help, ls, sysinfo, led, ping)
  • Notepad: Write and save notes
  • App Studio: Build HTML/CSS/JS apps with live preview
  • File Manager: Browse your saved files
  • Settings: Change WiFi, IP, LED brightness
  • System Info: Live temperature, RAM, CPU stats
  • LED Control: 8 colors + brightness slider
